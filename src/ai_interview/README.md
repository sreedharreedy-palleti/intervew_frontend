# AI Interview (`ai_interview`)

Frontend application for the **AI Voice & Technical Interview Simulation**.

## Structure

```
ai_interview/
├── components/          # Audio waveform indicators & visualizers
├── pages/               # InterviewPrecheck, InterviewRoom, InterviewReport, InterviewView
├── services/            # interviewApi.js
├── routes/              # InterviewRoutes.jsx
└── index.js
```

> **Note**: The backend APIs and desktop launcher for AI Interview are located in the main backend folder: `Backend/intervew_app`.
