# AI Assignment (`ai_assignment`)

Frontend application for the **AI Technical Coding Assignment & Examination**.

## Structure

```
ai_assignment/
├── components/          # Live webcam face detection & pre-exam verification
│   ├── LiveProctoringFeed.jsx
│   └── PreExamVerification.jsx
├── pages/               # AssignmentView.jsx & AssignmentView.css
├── sections/            # Code editor panel, test runner, problem viewer, security lock modals
├── services/            # assignmentApi.js
├── styles/              # Assignment CSS styles
├── routes/              # AssignmentRoutes.jsx
└── index.js
```

> **Note**: The backend APIs and desktop launcher for AI Assignment are located in the main backend folder: `Backend/assignment_app`.
